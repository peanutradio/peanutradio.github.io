## 네트워크

### Azure Front Door 엣지 액션 (GA)

무엇이 바뀌었나. Front Door가 클라이언트 요청·응답을 처리하는 도중에 가벼운 JavaScript 함수를 실행할 수 있게 됐다(2026-11-10 공지).

누가 신경 써야 하나. 헤더 조작이나 간단한 분기를 위해 원본(origin) 서버나 별도 프록시를 두던 팀이다.

도입 전 확인할 것. 함수에 걸리는 실행 시간·코드 크기 제한과 과금 방식은 피드 요약에 없다. 공지 원문과 Learn 문서에서 확인한다.

### Azure Front Door gRPC 지원 (프리뷰)

무엇이 바뀌었나. Front Door가 gRPC를 기본 지원하는 프리뷰가 시작됐다. 요약에 따르면 특정 서비스·메서드 단위로 호출을 라우팅한다.

누가 신경 써야 하나. gRPC 백엔드를 Front Door 뒤에 두고 싶은 팀이다.

도입 전 확인할 것. 프리뷰라 SLA 대상인지, 지원하는 gRPC 호출 형태(스트리밍 포함 여부)를 확인한다.

### Front Door Premium WAF 속도 제한 그룹화 (프리뷰)

무엇이 바뀌었나. 기본 동작은 속도 제한 규칙이 클라이언트 IP별로 요청을 따로 세는 것이다. 이를 묶어서 셀 수 있는 그룹화 기능이 프리뷰로 나왔다.

누가 신경 써야 하나. NAT 뒤 다수 사용자나 API 키 단위로 제한을 걸어야 하는 팀이다.

도입 전 확인할 것. 어떤 기준으로 그룹을 만들 수 있는지는 요약에 없다. 기존 규칙과의 우선순위도 함께 본다.

### Front Door Premium WAF AI 봇 규칙 세트 (프리뷰)

무엇이 바뀌었나. AI 크롤러·에이전트 중 일부는 허용하고 일부는 막고 싶을 때 쓰는 규칙 세트다. 공지는 robots.txt만으로는 한계가 있다는 점에서 출발한다.

누가 신경 써야 하나. 콘텐츠 사이트 운영자, 에이전트 트래픽을 구분해야 하는 팀이다.

도입 전 확인할 것. 탐지 방식과 오탐 가능성은 요약에 없다. 먼저 탐지(감사) 모드로 영향을 보는 방식이 안전해 보인다.

### Azure Route Server 듀얼스택 IPv4/IPv6 (프리뷰)

무엇이 바뀌었나. 두 주소 체계의 경로 교환을 지원한다. 기존 IPv4 연결은 그대로 유지된다고 한다.

누가 신경 써야 하나. NVA와 BGP로 경로를 교환하며 IPv6 전환을 준비하는 하이브리드 네트워크 담당자다.

도입 전 확인할 것. 사용 중인 NVA가 IPv6 BGP를 지원하는지, 기존 Route Server에 적용되는지 새로 만들어야 하는지 확인한다.

### Application Gateway 사용자 인증 + JWT 검증 (프리뷰)

무엇이 바뀌었나. 트래픽이 백엔드에 닿기 전에 OpenID Connect로 사용자를 로그인시키고 JWT를 검증하는 중앙 인증이 프리뷰로 나왔다.

누가 신경 써야 하나. 앱마다 인증 코드를 따로 두고 있는 웹 앱 운영팀이다.

도입 전 확인할 것. 지원하는 SKU와 IdP, 토큰 검증 실패 시 응답 동작을 확인한다.

## 보안·ID

### Azure Firewall for Containers (프리뷰)

무엇이 바뀌었나. Azure Firewall 보호를 컨테이너 워크로드로 넓히는 프리뷰다(2026-11-20 공지).

누가 신경 써야 하나. AKS 등에서 파드 단위 송신 통제가 필요한 보안 담당자다.

도입 전 확인할 것. 지원 대상 컨테이너 플랫폼, 기존 Azure Firewall SKU와의 관계, 과금을 원문에서 확인한다.

### AKS의 Intel TDX 기밀 VM (GA)

무엇이 바뀌었나. 기존 AKS CVM 노드 이미지가 AMD SEV-SNP만 지원하던 데서 Intel TDX까지 GA로 확장됐다.

누가 신경 써야 하나. 규제 산업에서 사용 중 데이터 보호(기밀 컴퓨팅)를 AKS에 적용하려는 팀이다.

도입 전 확인할 것. 지원 VM 크기와 리전, 그리고 같은 주 프리뷰로 나온 OS 디스크 암호화 지원(별도 공지)이 GA가 아니라는 점을 구분한다.

## AI·에이전트

### Azure AI Gateway (GA)

무엇이 바뀌었나. API Management의 AI Gateway 티어로 제공되던 것이 Azure AI Gateway라는 이름으로 GA가 됐다. 같은 주 API Management Premium v2도 GA로 35개 리전에서 제공된다고 공지됐다.

누가 신경 써야 하나. 여러 모델·에이전트 호출을 한 관문에서 통제하려는 플랫폼팀이다.

도입 전 확인할 것. 기존 APIM AI Gateway 티어 사용자는 명칭 변경 외에 가격·구성이 달라지는지 원문을 확인한다.

## 컴퓨트·개발

### Azure Functions .NET 11 지원 (GA)

무엇이 바뀌었나. Functions가 .NET 11을 GA로 지원한다(2026-11-10 공지).

누가 신경 써야 하나. .NET 8·9 종료 일정에 맞춰 올릴 대상을 찾는 팀이다.

도입 전 확인할 것. 지원 호스팅 모델(격리 작업자 등)과 플랜별 제약은 요약에 없다. 지원 언어 문서를 확인한다.

### Azure Linux 4.0 (GA)

무엇이 바뀌었나. Microsoft Ignite의 일환으로 Azure Linux 4.0이 GA로 공개됐다.

누가 신경 써야 하나. Azure Linux를 AKS 노드 OS로 쓰는 팀이다.

도입 전 확인할 것. 이전 버전에서의 업그레이드 경로와 AKS 지원 시점을 확인한다.

## 데이터·스토리지·백업

### Azure HorizonDB (GA)

무엇이 바뀌었나. 초저지연이 필요한 시나리오를 겨냥한 Azure HorizonDB가 GA가 됐다.

누가 신경 써야 하나. PostgreSQL 계열 대안을 검토하는 데이터 플랫폼 담당자다.

도입 전 확인할 것. 지원 리전, 이번 주 함께 나온 백업·감사·Azure Policy 공지의 상태(GA/프리뷰 혼재)를 항목별로 확인한다.

### 디스크 불변 스냅샷 (프리뷰)

무엇이 바뀌었나. 모든 디스크 유형의 스냅샷에 불변성 정책을 걸어 최대 90일간 삭제를 막는다.

누가 신경 써야 하나. 랜섬웨어·실수 삭제 대비 복구 지점을 보호해야 하는 백업 담당자다.

도입 전 확인할 것. 프리뷰이므로 운영 백업 정책에 쓰기 전에 정책 해제 가능 여부와 지원 지역을 확인한다.

### Compute Gallery 소프트 삭제 (GA)와 VM 구독 간 백업 (GA)

무엇이 바뀌었나. 갤러리 이미지 버전을 실수로 지워도 복구할 수 있고, Azure Backup은 다른 구독의 Recovery Services 자격 증명 모음으로 VM을 보호할 수 있다.

누가 신경 써야 하나. 이미지 파이프라인과 중앙 백업 구독 구조를 운영하는 팀이다.

도입 전 확인할 것. 소프트 삭제 보존 기간과 비용, 구독 간 백업에 필요한 권한 구성을 원문에서 확인한다.

## 은퇴·마감 알림
